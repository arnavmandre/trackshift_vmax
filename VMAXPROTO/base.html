VMAX · UI prototype

Built from the top “VMAX - Steward Review” frame in Figma. This file runs locally without a server, installation, or model.

Open one or more videos, search and filter the queue, change playback speed, set the source FPS for stepping, make a manual crop, and bookmark moments for review.

Choose a human assessment, write notes, then select Save clip review. Export decisions downloads your saved assessments and drafts as JSON. Video bytes are never uploaded or stored in the review log.

Reopen the original video files after a refresh to resume playback. Reviews persist where browser storage is available. Time-based stepping uses your configured FPS and does not guarantee frame-exact navigation for variable-frame-rate video.
