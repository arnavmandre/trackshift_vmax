# Event implementation instructions

This repository's main branch is for newly developed hackathon work. Read README.md before implementing.

- Keep prior work disclosed. Never alter dates or rewrite history to conceal its origin.
- Do not import, cherry-pick, port, lightly rewrite, or load code or weights from the pre-event VMAX snapshot as event-built work.
- Historical benchmark results are not results for a new implementation.
- A fresh implementation may use permitted general algorithms, frameworks and public references. Cite actual dependencies and keep provenance.
- Pre-event dataset preparation is allowed by the supplied FAQ, but disclose reused data and follow any stricter organiser instruction. Dataset permission does not establish permission to reuse the trained model or application.
- If organisers explicitly allow incremental prototype reuse, record the scope and source of that permission before reusing components; report only the event delta as new work.
- Record implementation commits, tests and results in EVENT_WORK.md. Do not invent elapsed time or evidence.
- Use a fresh final holdout for new model selection/evaluation. Do not tune to historical test answers.
- These instructions do not assert eligibility; organisers have final authority.
